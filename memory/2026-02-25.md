### Coconut 论文分析
- Yu 发了 Coconut (Chain of Continuous Thought) 的 Section 4 全文
- 核心：连续空间 hidden state 天然是叠加态（superposition），可同时编码多条候选路径
- CoT = 贪心搜索（选了就回不了头），Coconut = 隐式 BFS（保持多路径并行探索）
- ProsQA 上 Coconut 97% vs CoT 77.5%，但 GSM8K 上 CoT 反而赢（42.9 vs 34.1）
- 关键限制：curriculum training 脆弱、只在 GPT-2 验证、不可解释、叠加态容量有限、没有 scaling law

### Yu 的问题链
1. "为什么 latent reasoning 没 work？" → 分析了 Coconut 的 5 个根本限制
2. "Large Concept Model 为啥也 G 了？" → 粒度太粗（句子级 SONAR embedding）、解码瓶颈、token 级精度丢失、训练数据 mismatch
3. 共同结论：连续空间的好处（平滑、并行探索）和代价（精度丢失、不可解释、解码误差）是绑定的

### 我提出的 Rate-Distortion 框架 idea
- Hard mask → soft mask 可以看成 rate-distortion 问题
- Hard mask = R-D curve 两个端点（R=0 全 mask，R=H(X) 不 mask）
- Soft mask = 在 R-D curve 上连续移动
- 最优 masking schedule = R-D curve 的最优路径
- 连接 Greg 的信息论专长 + Yu 的 order robustness + Coconut 的叠加态

### DSL 论文 (arXiv:2602.16169) — Greg 组的工作！
- Yu 发了这篇，作者包括 Greg Ver Steeg
- **Discrete Stochastic Localization**: SNR-invariant denoiser，统一连续/离散 corruption
- 核心：token embedding 放到单位超球面，posterior 只依赖 z 不依赖 SNR
- Remasking = per-token SNR 路径上的回溯（Figure 1a 统一了 AR/diffusion/remasking）
- Mixed corruption training（endpoint + continuous SNR）解决 train-inference mismatch
- 4x fewer denoiser evaluations 达到同等 MAUVE
- 比 SM 和 EvoToken 都更 principled——从训练框架层面解决 soft mask 问题

### DSL 之后的可能方向（我的建议）
1. DSL + reasoning：DSL 的连续 SNR 状态 = 叠加态，能否证明具有 Coconut 式 BFS 性质？
2. 最优 SNR 路径：给定 compute budget，怎么分配 per-token SNR 增长速度？（rate-distortion）

- 讨论 GEB (Gödel, Escher, Bach) 的核心论点：
  - 类比 vs strange loop 是不同层级的概念
  - 类比 = 智能的动词（认知操作），strange loop = 意识的名词（结构）
  - 类比是产生自指的手段，自指是类比的特殊结果
  - Hofstadter 的体系漂亮但不闭合："自指→意识"更像深刻直觉而非严格推导
- 自指是复杂系统的必然特征：Gödel 不完备定理证明表达力够强的系统必然能自指
- 从图灵机讲到图灵完备：
  - 图灵机 = 极简计算模型（读、写、移、变状态）
  - 图灵完备 = 能模拟通用图灵机（条件分支 + 循环 + 无限存储）
  - 冯·诺依曼架构 = 通用图灵机的工程实现，PC = 图灵机的状态
- Transformer 图灵完备性：
  - 标准 Transformer 不是（固定深度）
  - 加无限精度是（Pérez et al. 2019，时间步展开到序列空间维度）
  - RNN 更自然（Siegelmann & Sontag 1996，隐藏状态编码纸带）
  - LLM + CoT ≈ 用外部纸带扩展计算深度
  - dLLM + remask = 另一条通往动态计算深度的路
- SICP 简介：五章结构，第四章（用 Scheme 写 Scheme 解释器）= GEB 的 strange loop 编程实现

### 我的 review 意见
1. **Local Cost Theorem 一般性**（Greg 也标注了）— Girsanov 推导假设 drift 无显式时间依赖，一般 SDE 有 ∂f/∂t 项，需验证是否在取期望后消失
2. **ν=0 是否最优** — 有真实 trade-off：ν=0 是 ODE，low-SNR 区域 score 变化剧烈导致 stiff；加噪声可以 smooth stiffness
3. **J_x̂ 到 J_v 的替换** — 用 ‖J_x̂‖² 代替 ‖J_v‖² 避免 (1-t)⁻² 数值问题，但改变了 metric 几何意义，需要说清是 approximation
4. **Modeling error 逻辑跳跃** — 从 p* 下的 conditional entropy 到 q_{θ,π} 下的 accumulated error 缺一个 bound
5. **MI proxy 等价性前提** — H(X|X_{t_x}) 不依赖 Z ordering 的前提是独立加噪，如果 model 有 cross-attention 则不严格成立
