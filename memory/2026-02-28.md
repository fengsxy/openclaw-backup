## Azure Spot VM Research
- Yu asked about Azure spot VM eviction frequency, specifically A10 GPU (NVads_A10_v5)
- Key findings:
  - Azure portal shows eviction rate by SKU/region (past 28 days): 0-5%, 5-10%, 10-20%, 20%+
  - GPU spot more prone to eviction than CPU (capacity tight, ML demand high)
  - A10 quota itself hard to get — multiple Reddit reports of long waits
  - Eviction notice: 30s theoretical, 10-15s actual reported
  - Hot region + hot SKU = could be evicted in minutes to hours
  - Cold region + off-peak = could last hours to days
  - Recommendation: frequent checkpointing, multi-region failover, or consider reserved instances

## Cloud GPU Research (continued ~15:00 UTC)
- Yu exploring using startup credits (YC?) for GPU instances
- Azure YC/Founders Hub credits: technically can pay for GPU, but sponsorship subscriptions have extra quota restrictions on GPU SKUs — frequently denied, need to fight support for weeks. A10 easier than A100.
- AWS credits (Activate/YC): no extra GPU restriction on credits themselves, just need quota increase. G5 (A10G) quota often approved instantly. Much easier than Azure.
- AWS GPU instance naming:
  - G5 series = A10G (g5.xlarge 1x A10G $1/hr OD, ~$0.3-0.5 spot)
  - G6 series = L4
  - G4dn = T4 (cheapest)
  - P4d = A100 40GB, P4de = A100 80GB, P5 = H100
- All GPU instances are EC2 — launch from EC2 console or CLI
