## Yu 的 Diffusion Optimal Path 项目 — 深度讨论

### 论文审阅（推导问题）
- Local Cost Theorem: ∂f/∂t 项是 O(Δt³)，比 Jacobian 项低一阶，定理在 leading order 是 general 的
- 标量 cost → 2D metric 推广：严格推导下 leading order metric 是对角的（无 Δt_p·Δt_d 交叉项），文中的 off-diagonal H_pd 需要额外假设
- 正确的对角 metric: G = diag(S_p + C_{d→p}, w·S_d + w·C_{p→d})
- J_x̂ vs J_v 问题：discretization error 取决于 J_v = (J_x̂ - I)/(1-t)，不是 J_x̂。文中用 ‖J_x̂‖² 做 cost map 在 high-t 区域系统性低估真实 error
- 建议：Hutchinson estimator 改为测 ‖(J_x̂ - I)·r‖²，再除以 (1-t)²

### Local → Global 理论补全
- KL chain rule for Markov chains 给出精确分解：D_KL(P‖Q) = Σ_k E[local KL_k]
- Data processing inequality: D_KL(p_data ‖ q_generated) ≤ D_KL(P‖Q)
- 完整逻辑链：minimize DP cost → minimize path KL → minimize generation quality gap
- 引用：Cover & Thomas (KL chain rule), Chen et al. 2023 (discretization bounds)

### Flow Matching vs Stochastic Localization
- Greg 的 SL: z = snr·x + √snr·ε → J_x̂ = I/snr → 0 at high SNR
- Yu 的 FM: z = t·x + (1-t)·ε → J_x̂ = I/t → I at t→1（不趋零）
- 这解释了为什么 Greg 的理论预测（high SNR cost→0）跟 Yu 的实验不一致——参数化不同

### Grid 问题
- Yu 目前用 uniform in t，可以不改，但 cost map 必须用 J_v 而不是 J_x̂
- uniform in log-SNR 是可选优化，不是必须

### 新 Idea：Posterior Sharpening 跳步
- 核心观察：diffusion E[x₀|x_t] 是加权平均（blurry），LM P(x₀|x_t) 是 categorical（可一步 sample）
- Yu 提出：用 γ-sharpened likelihood N(x_t; α_t·x₀, σ²_t/γ) 来加速
- γ > 1 等价于假装 SNR 更高，让 posterior 更 sharp，实现跳步
- Gaussian posterior 下 sharpening 不改变均值，只缩小 variance → 对 deterministic ODE 无效，对 SDE 有效
- 搜索后未发现直接相关的已有工作（CFG 最接近但需要两次 forward pass）
- 潜在价值：不改架构、不需额外 forward pass、有信息论解释、可与 metric 框架结合

## Tempered Diffusion 论文 Prior Work 搜索 (晚间)

### Yu 发来一篇 "Tempered Diffusion" 论文草稿
- 核心 idea：对 forward likelihood p(x_t|x_0) 做 power scaling (γ)，等价于 variance scaling σ²_t/γ
- Tempered Tweedie identity: D_γ = (x_t + σ²_t/γ · s_γ) / α_t
- Tempered probability flow ODE: diffusion coefficient 缩放 g(t)/√γ
- 大 γ → mode-seeking，posterior 集中到 MAP solution
- 和 Flow Map Matching 的联系：tempering 修改 flow map 几何

### 最相似的已有工作
1. **Temporal Score Rescaling (TSR)** — arXiv:2510.01184, CMU+Stanford, Oct 2025
   - 最直接的 prior work，核心操作几乎一样（rescale score → sharper/flatter 分布）
   - 关键区别：TSR 做 local temperature（每个 mode variance 缩放，权重不变），Yu 的做 global tempering（likelihood powering 改变 mode 权重）
   - TSR 的 rescaling 是 time-dependent λ(k,t)，Yu 的 γ 是 time-independent
   - TSR 证明了 constant scaling 会 mode drop，time-dependent 才对
   - TSR 有 5 个领域实验（image, depth, pose, robot, protein）
2. **CFG is a Predictor-Corrector** — arXiv:2408.09000, Apple, NeurIPS 2024 Workshop
   - 证明 CFG ≠ sampling p(x|c)^γ · p(x)^{1-γ}（推翻常见误解）
   - CFG = DDIM predictor + Langevin corrector for gamma-powered distribution
3. **CFG 本身** — guidance scale w+1 本质就是 γ，对 condition likelihood 做 power scaling

### 结论
- 核心 insight（score rescaling → sharper generation）已被 TSR 覆盖
- Yu 的框架更 clean（tempered Tweedie identity），但 novelty 不够独立成 paper
- 可能的差异化方向：FMM 联系、training-time tempering、time-independent vs time-dependent 的理论比较
