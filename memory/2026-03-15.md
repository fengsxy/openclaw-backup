### 关键发现
- **Block-wise 是 AR→dLLM 最优转换范式**：保留权重分布 + 支持 KV cache
- **Clean context 贡献 +9.46%**（Efficient-DLM），但 SDAR/LLaDA 2.0 都没用——低垂果实
- **On-Policy Distillation = RL**（Reopold 严格证明）
- **EOPD 发现 reverse KL 在高 entropy token 上失败**，混合 forward+reverse KL 提升 Pass@8 最高 +5.05
- **Step Distillation 在 dLLM 中严重不足**——只有 CDLM 和 SDTT，巨大研究空白
- **Gated DeltaNet 是唯一同时具备遗忘+精确修正的 linear attention**，天然适合 dLLM 的 denoising 语义
